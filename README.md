# 🌼 Flower Shop Website 💐
A complete flower shop web application built using HTML, CSS, JavaScript, PHP, and MySQL. This project allows users to browse flowers, book orders, give feedback, and contact the shop. Admins can manage flowers, feedback, orders, and users from a secure dashboard.

## 🚀 Features

### 🛍️ User Side:
- Browse flowers by category
- View flower details in card layouts
- Add flowers to cart
- Book flower orders
- Submit feedback with star rating & image
- Contact form 

### 🛠 Admin Dashboard:
- Manage Admin (Add/Update/change password)
- Manage Categories (Add/Update/Delete)
- Manage flowers (Add/Update/Delete)
- View customer feedbacks
- Manage orders and status updates
- Secure login required to access

---

## 🛠 Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Image Upload:** via `$_FILES`   
- **Server:** XAMPP / Localhost
